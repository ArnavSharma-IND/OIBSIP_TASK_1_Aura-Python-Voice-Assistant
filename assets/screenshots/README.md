## How to Add Your Own Screenshots

1. Run the assistant GUI:
   ```bash
   python main.py
   ```
2. Capture a screenshot using Windows Snipping Tool (`Win + Shift + S`).
3. Save the image into this folder as `gui_preview.png` or `console_demo.png`.
4. Link it in `README.md`.
